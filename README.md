# 时疠纪 · Chronicle of Pestilence

手机优先的架空王朝瘟疫策略游戏当前开发版。策划时使用《疫》作为项目代号，原文在 [`《疫》v0.1_Codex文档包`](./《疫》v0.1_Codex文档包/README.md)。

## 启动

需要 Node.js 20.19+。

```powershell
npm install
npm run dev
```

浏览器打开终端显示的本地地址，通常是 `http://localhost:5173/`。

## 已可玩

新局选「疫」→ 命名 → 阅序章 → 选四种疫病之一 → 地图选地区首次降疫 → 查看地区、驭疫、借势、藏疫 → 推演下一旬。每旬结算传播、事件、六方行动与三项全局数值，并自动保存到当前浏览器。疫痕达到 20 / 45 / 75 可再次降疫；「医」入口暂锁定。

一世的终点是四个终局之一：**易鼎**（京师沦疫、朝警鼎沸、京畿秩序崩解）、**蚀国**（多数州郡行政与治理停摆）、**大疫**（病者遍及天下）为疫之胜局；若疫源被官府尽数扑灭、你也再无力降疫，则是**疫灭**的败局。察觉你的疫、治理又高的地方会真的扑疫，重疫之地的秩序与治理会逐旬蚀空——王朝不是静止的沙盘。

第 10 旬起脚本大事结束，事件池继续按朝警、疫痕与疫情状态生成天下大事（粮价、流民、断道、义仓、蝗灾、诏焚疫区……），其中一部分仍可借势。

疫册现已加入四疫成长系统：寒疫、黑疽、水殇、赤疮各有两条三阶疫路。疫历通过存续与借势累积，不作为消费货币；选择首阶后会锁定该疫本世的成长路线，已解锁疫性会实际改变传播、增长、察觉或治理压制。

地图为 25 个架空节点，支持拖动和缩放。手机使用底部导航与地区抽屉；桌面使用三栏。档案只有一个本地存档槽，新局会先确认覆写。

## 校验

```powershell
npm test
npm run build
```

数值为游戏化规则，不用于模拟真实传染病。当前没有「医」身份和多档案位。


## 疫种扩展

除开局四种常疫（寒疫、黑疽、水殇、赤疮）外，现已加入后续可解锁的牲疫、禽疫、血疫与尸疫。牲疫与禽疫在疫痕 20 后显现，血疫在疫痕 45 后显现；尸疫属于特殊灾厄，需要疫痕 75，且已有一处病者估计 500+ 的重疫之地才可苏醒。禽疫的「飞羽」路线拥有跨越一个中间节点的远跃传播能力。
